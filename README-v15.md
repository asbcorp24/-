# STL Cosmic Morph v15 — локальный сервер

Python 3.10+ без сторонних пакетов. Скачайте репозиторий целиком.

## Запуск

```bash
python server.py
```

Откройте **http://127.0.0.1:8000/** (не запускайте HTML двойным кликом как file://).

1. Загрузите STL (несколько одновременно).
2. Для каждой модели выберите название, ориентацию X/Y/Z и до 4 фотографий.
3. Настройте длительность показа, фотокуб, формирование/пролёт/разрушение туннеля, скорость вращения, изгиб и Bloom.
4. Нажмите «Сохранить на сервер». Файлы сохранятся в `projects/default/assets/`, настройки — в `projects/default/project.json`.
5. После перезапуска откройте страницу и нажмите «Загрузить с сервера».
6. «⬇ JSON» экспортирует настройки с URL файлов, «⬆ JSON» загружает их. **JSON не включает бинарные STL и изображения**: они должны оставаться на том же сервере.

## API

- `GET /api/project` — получить проект.
- `POST /api/project` — сохранить JSON проекта.
- `POST /api/upload` — загрузить файл, заголовок `X-Filename`, тело — двоичные данные.

Ограничения: до 100 МБ на файл, до 2 МБ JSON, до 4 фотографий на модель. Сервер привязан к `127.0.0.1` и предназначен только для локальной разработки. Не выставляйте его напрямую в интернет без авторизации и дополнительных проверок безопасности.

```bash
python server.py --port 8080
```

Библиотеки Three.js загружаются с CDN, поэтому для первой загрузки страницы нужен интернет.
